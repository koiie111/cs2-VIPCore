# VIP_C4Effect

Частицы при установке и обезвреживании бомбы. Эффект установки появляется на заложенной C4 и держится заданное время (или до взрыва / обезвреживания / конца раунда), эффект обезвреживания вспыхивает на месте бомбы в момент дефьюза. Игрок целиком настраивает эффекты в меню `!vip` (см. «Меню игрока»).

Порт модуля `C4Effect` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/C4Effect.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_C4Effect/VIP_C4Effect.csproj -c Release
   ```
2. Скопируйте папку `VIP_C4Effect` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Загрузите файлы частиц (`.vpcf` / `.vpcf_c`) на сервер и клиентам (Workshop-аддон или FastDL — зависит от вашей схемы раздачи ресурсов).
4. Добавьте фичу `C4Effect` в нужные группы `vip.json` (см. ниже) и перезапустите сервер или смените карту. `css_vip_reload` подхватит новые записи, но **частицы предзагружаются при старте карты**, поэтому новый `.vpcf` заработает только после смены карты.

Строки меню берутся из `lang/*.json` ядра (ключи `C4Effect` и `c4effect.*`). Обновите `lang` ядра до версии с этим модулем, иначе пункты меню будут показаны ключами.

## Конфиг (`vip.json`)

Значение фичи — список эффектов. Поле `defuse` разделяет их на две категории: `false` — эффект установки, `true` — эффект обезвреживания.

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "C4Effect": [
          {
            "name": "Smoke",
            "particle": "particles/explosions_fx/explosion_smokegrenade_s1_child_smoke_bottom.vpcf",
            "lifetime": 6,
            "defuse": false
          }
        ]
      }
    },
    "VIP2": {
      "Values": {
        "C4Effect": [
          {
            "name": "Smoke",
            "particle": "particles/explosions_fx/explosion_smokegrenade_s1_child_smoke_bottom.vpcf",
            "lifetime": 6,
            "defuse": false
          },
          {
            "name": "Fog",
            "particle": "particles/ambient_fx/cbbl_movie_fog.vpcf",
            "lifetime": 0,
            "defuse": false
          },
          {
            "name": "Splash",
            "particle": "particles/water_impact/water_splash_02_continuous.vpcf",
            "lifetime": 4,
            "defuse": true
          }
        ]
      }
    }
  }
}
```

Пути в примере — условные: подставьте частицы, которые реально есть на сервере или в вашем аддоне. Разные группы могут иметь разные наборы эффектов.

Имена полей — строго в нижнем регистре.

| Поле | Описание |
|------|----------|
| `name` | название в меню (обязательно, служит и идентификатором выбора — не меняйте его у уже выданных эффектов, иначе сохранённый выбор игроков сбросится на первый эффект категории) |
| `particle` | путь к файлу частицы `.vpcf` (обязательно) |
| `lifetime` | сколько секунд держится эффект. Для эффекта установки `0` — пока бомба не взорвётся, не будет обезврежена или не начнётся новый раунд; для эффекта обезвреживания `0` означает 3 секунды |
| `defuse` | `false` (по умолчанию) — эффект установки, `true` — эффект обезвреживания |

Запись без `name` или без `particle` игнорируется. Если в группе нет ни одной записи категории, соответствующий пункт меню скрыт. Все файлы из `particle` всех групп автоматически добавляются в предзагрузку карты (читаются прямо из `vip.json`).

## Меню игрока

Пункт `C4Effect` в `!vip` открывает меню:

| Пункт | Что делает |
|-------|------------|
| Эффект установки: имя | открывает список эффектов установки группы + «Выключить» (скрыт, если в группе таких нет) |
| Эффект обезвреживания: имя | то же для эффектов обезвреживания |
| Вижу свой эффект: Да/Нет | показывать ли эффект самому себе |
| Мой эффект видят: Все/Союзники/Только я | кому передаётся эффект, который вызвали вы |
| Чужие эффекты: Показывать/Только союзники/Скрыть | чьи эффекты видите вы (доступно и при выключенных своих) |
| Сбросить настройки | возвращает выбор эффектов (первый в категории) и все параметры видимости по умолчанию |

Без сохранённого выбора VIP получает первый эффект своей категории. Все настройки хранятся одной записью в cookie ядра и сохраняются между сессиями. Эффект принадлежит тому, кто поставил или обезвредил бомбу, и показывается по его настройкам.

## Отличия от оригинала

- Фича регистрируется как `Selectable` в `VipFeatureBase`: игрок включает и выключает её в `!vip`, а конфиг лежит в `vip.json` (в оригинале — отдельный модуль на `VipModule` с `GroupValue`). Поле `required` оригинала не поддерживается — для разных наборов используйте группы.
- Выбор эффекта хранится в cookie ядра вместо `CategorySetting` оригинала; добавлены настройки видимости: свой эффект, кто видит мой, чьи чужие вижу.
- Скрытие эффекта от других игроков сделано через `Listeners.CheckTransmit` API CounterStrikeSharp, а не через общий `EffectHide` оригинального ядра.
- Эффект не создаётся для ботов.
