# VIP_PlayerParticle

Крепит к VIP-игроку частицу (эффект вокруг персонажа), которая следует за ним, пока он жив. Эффект появляется при спавне и пропадает при смерти, смене команды и в конце раунда. Игрок целиком настраивает эффект в меню `!vip` (см. «Меню игрока»).

Порт модуля `PlayerParticle` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/PlayerParticle.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_PlayerParticle/VIP_PlayerParticle.csproj -c Release
   ```
2. Скопируйте папку `VIP_PlayerParticle` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Загрузите файлы частиц (`.vpcf` / `.vpcf_c`) на сервер и клиентам (Workshop-аддон или FastDL — зависит от вашей схемы раздачи ресурсов).
4. Добавьте фичу `PlayerParticle` в нужные группы `vip.json` (см. ниже) и перезапустите сервер или смените карту. `css_vip_reload` подхватит новые записи, но **частицы предзагружаются при старте карты**, поэтому новый `.vpcf` заработает только после смены карты.

Строки меню берутся из `lang/*.json` ядра (ключи `PlayerParticle` и `playerparticle.*`). Обновите `lang` ядра до версии с этим модулем, иначе пункты меню будут показаны ключами.

При загрузке модуля на работающем сервере меню доступно сразу, но создание эффектов откладывается до следующей смены карты и предзагрузки ресурсов. Принудительная смена карты или перезапуск не требуются.

## Конфиг (`vip.json`)

Значение фичи — список эффектов:

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "PlayerParticle": [
          {
            "name": "Fire",
            "particle": "particles/burning_fx/env_fire_medium.vpcf",
            "offset": 15
          }
        ]
      }
    },
    "VIP2": {
      "Values": {
        "PlayerParticle": [
          {
            "name": "Fire",
            "particle": "particles/burning_fx/env_fire_medium.vpcf",
            "offset": 15
          },
          {
            "name": "Aura",
            "particle": "particles/myaddon/aura.vpcf",
            "offset": 40
          }
        ]
      }
    }
  }
}
```

Пути в примере — условные: подставьте частицы, которые реально есть на сервере или в вашем аддоне. Разные группы могут иметь разные наборы эффектов.

Имена полей — строго в нижнем регистре.

| Поле | Описание |
|------|----------|
| `name` | название в меню (обязательно, служит и идентификатором выбора — не меняйте его у уже выданных эффектов, иначе сохранённый выбор игроков сбросится на первый эффект группы) |
| `particle` | путь к файлу частицы `.vpcf` (обязательно) |
| `offset` | высота точки крепления над ногами игрока, по умолчанию `15` (в оригинале то же значение) |

Запись без `name` или без `particle` игнорируется. Значение `offset` из конфига служит значением по умолчанию — игрок может изменить высоту в меню. Все файлы из `particle` всех групп автоматически добавляются в предзагрузку карты (читаются прямо из `vip.json`).

## Меню игрока

Пункт `PlayerParticle` в `!vip` открывает меню:

| Пункт | Что делает |
|-------|------------|
| Эффект: имя | открывает список эффектов группы + «Выключить»; выбранный эффект сразу применяется к живому игроку |
| Высота: N | по клику переключает 0 → 10 → 15 → 25 → 40 → 60 → 80 → 100 |
| Вижу свой эффект: Да/Нет | показывать ли эффект самому себе (удобно, если он закрывает обзор) |
| Мой эффект видят: Все/Союзники/Только я | кому передаётся ваш эффект |
| Чужие эффекты: Показывать/Только союзники/Скрыть | чьи эффекты видите вы (доступно и при выключенном своём эффекте) |
| Сбросить настройки | возвращает высоту из конфига и все параметры видимости по умолчанию |

По умолчанию эффект выключен: игрок включает его, выбирая эффект в `!vip`. Ранее сохранённый выбор сохраняется. Все настройки хранятся одной записью в cookie ядра и сохраняются между сессиями; пункты настройки своего эффекта скрыты, пока он выключен.

## Отличия от оригинала

- Фича регистрируется как `Selectable` в `VipFeatureBase`: игрок включает и выключает её в `!vip`, а конфиг лежит в `vip.json` (в оригинале — отдельный модуль на `VipModule` с `GroupValue`).
- Добавлены персональные настройки: высота, показ своего эффекта и видимость для себя и других игроков (в оригинале игрок мог только выбрать эффект по имени).
- Скрытие эффекта от других игроков сделано через `Listeners.CheckTransmit` API CounterStrikeSharp, а не через общий `EffectHide` оригинального ядра.
- Эффект крепится к игроку через `SetParent`, а не создаётся вспомогательными утилитами оригинального ядра.
- Эффект не создаётся для ботов.
