# VIP_HitSound

Проигрывает звук, когда VIP-игрок попадает во врага. Звук слышат сам стрелок и наблюдатели, которые смотрят за ним. Есть две категории — обычное попадание и хедшот; игрок выбирает звук для каждой (или выключает её) в меню `!vip`.

Порт модуля `HitSound` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/HitSound.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_HitSound/VIP_HitSound.csproj -c Release
   ```
2. Скопируйте папку `VIP_HitSound` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Добавьте фичу `HitSound` в нужные группы `vip.json` (см. ниже) и выполните `css_vip_reload` либо перезапустите сервер.

Строки меню берутся из `lang/*.json` ядра (ключи `HitSound` и `hitsound.*`). Обновите `lang` ядра до версии с этим модулем, иначе пункты меню будут показаны ключами.

## Конфиг (`vip.json`)

Значение фичи — список звуков:

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "HitSound": [
          { "name": "Killcard", "path": "sounds/ui/killcard_1.vsnd" },
          { "name": "Ping", "emit": "UI.PlayerPing", "volume": 1.0, "hs": true }
        ]
      }
    }
  }
}
```

Имена полей — строго в нижнем регистре.

| Поле | Описание |
|------|----------|
| `name` | название в меню (обязательно, служит и идентификатором выбора — не меняйте его у уже выданных звуков, иначе сохранённый выбор игроков сбросится) |
| `path` | путь к своему звуковому файлу; проигрывается на клиенте командой `play` |
| `emit` | имя встроенного soundevent игры (например `UI.PlayerPing`). Если заданы и `emit`, и `path`, используется `emit` |
| `volume` | громкость для `emit`, по умолчанию `1.0`; `0` — звук не играет. Для `path` громкость не применяется |
| `hs` | `true` — звук попадает в категорию «Хедшот», `false` (по умолчанию) — в «Обычное попадание» |

Запись без `name` или без `path`/`emit` игнорируется. Категория, в которой нет звуков, в меню не показывается.

## Как работает

- Срабатывает на `player_hurt`, когда стреляет VIP с включённой фичей. Попадания по себе, по союзникам (если не включён `mp_teammates_are_enemies`) и от ботов игнорируются.
- При попадании в голову играет звук из категории «Хедшот»; если он не выбран — звук из «Обычного попадания».
- Пока игрок ничего не выбирал: «Обычное попадание» использует первый звук своей категории, «Хедшот» отключён (на хедшоте играет обычный звук).
- Выбор хранится в cookie ядра (`hitsound_normal`, `hitsound_hs`) и сохраняется между сессиями. Значение `off` — категория выключена.
- При выборе звука в меню он один раз проигрывается для предпросмотра.
- Наблюдатели слышат звук того, за кем они следят.

## Важно

- Звук через `path` проигрывается командой `play` на клиенте, поэтому файл должен быть у игроков (Workshop-аддон, FastDL или встроенный в игру). Если файла нет, звука не будет.
- Не каждое имя встроенного звука работает через `emit`. Проверенные: `UI.PlayerPing`, `UI.Lobby.Chat`, `UI.CompetitiveAccept`, `UI.CoinLevelUp`.
- Фича типа `Selectable`: пункт `HitSound` в `!vip` открывает меню выбора, а не переключает фичу.
