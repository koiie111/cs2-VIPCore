# VIP_Outfit

Надевает на VIP-игрока носимые модели (шляпы, очки, рюкзаки и т. п.), которые крепятся к модели игрока и следуют за ним, пока он жив. Предметы появляются при спавне и пропадают при смерти, смене команды и в начале раунда. Игрок целиком настраивает экипировку в меню `!vip` (см. «Меню игрока»).

Порт модуля `Outfit` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/Outfit.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_Outfit/VIP_Outfit.csproj -c Release
   ```
2. Скопируйте папку `VIP_Outfit` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Загрузите модели (`.vmdl` / `.vmdl_c`) на сервер и клиентам (Workshop-аддон или FastDL — зависит от вашей схемы раздачи ресурсов).
4. Добавьте фичу `Outfit` в нужные группы `vip.json` (см. ниже) и перезапустите сервер или смените карту. `css_vip_reload` подхватит новые записи, но **модели предзагружаются при старте карты**, поэтому новая модель заработает только после смены карты.

Строки меню берутся из `lang/*.json` ядра (ключи `Outfit` и `outfit.*`). Обновите `lang` ядра до версии с этим модулем, иначе пункты меню будут показаны ключами.

## Конфиг (`vip.json`)

Значение фичи — объект: ключ — **категория** (слот), значение — список предметов. Из каждой категории игрок носит не более одного предмета, а категорий может быть сколько угодно.

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "Outfit": {
          "hat": [
            { "name": "Cap", "model": "models/myaddon/outfit/cap.vmdl" }
          ]
        }
      }
    },
    "VIP2": {
      "Values": {
        "Outfit": {
          "hat": [
            { "name": "Cap", "model": "models/myaddon/outfit/cap.vmdl" },
            { "name": "Crown", "model": "models/myaddon/outfit/crown.vmdl", "required": "@css/vip" }
          ],
          "glasses": [
            { "name": "Sunglasses", "model": "models/myaddon/outfit/sunglasses.vmdl" },
            { "name": "Terrorist mask", "model": "models/myaddon/outfit/mask_t.vmdl", "team": "T" }
          ],
          "back": [
            { "name": "Backpack", "model": "models/myaddon/outfit/backpack.vmdl" }
          ]
        }
      }
    }
  }
}
```

Пути в примере — условные: подставьте модели, которые реально есть на сервере или в вашем аддоне. Разные группы могут иметь разные категории и наборы предметов.

Имена полей — строго в нижнем регистре.

| Поле | Описание |
|------|----------|
| `name` | название в меню (обязательно, служит и идентификатором выбора — не меняйте его у уже выданных предметов, иначе сохранённый выбор игроков сбросится) |
| `model` | путь к модели `.vmdl` (обязательно) |
| `team` | необязательно: `T` или `CT` — предмет доступен только в этой команде |
| `required` | необязательно: право или группа CounterStrikeSharp (`@css/vip`, `#css/admin`), нужное для этого предмета |

Запись без `name` или без `model` игнорируется; предметы, недоступные игроку по `required`/`team`, в его меню не показываются, а категория без доступных предметов скрывается целиком. Название категории в меню — ключ с заглавной первой буквой (`hat` → «Hat»). Все файлы из `model` всех групп автоматически добавляются в предзагрузку карты (читаются прямо из `vip.json`).

## Меню игрока

Пункт `Outfit` в `!vip` открывает меню:

| Пункт | Что делает |
|-------|------------|
| Категория: предмет | по одному пункту на каждую доступную категорию; открывает список предметов + «Снять». Выбранный предмет сразу применяется к живому игроку |
| Вижу свою экипировку: Да/Нет | показывать ли экипировку самому себе (удобно, если она закрывает обзор) |
| Мою экипировку видят: Все/Союзники/Только я | кому передаётся ваша экипировка |
| Чужая экипировка: Показывать/Только союзники/Скрыть | чью экипировку видите вы (доступно и пока ничего не надето) |
| Снять всё | снимает предметы всех категорий |
| Сбросить настройки | возвращает все параметры видимости по умолчанию (выбранные предметы не трогает) |

По умолчанию ничего не надето — VIP сам выбирает предметы в меню. Выбор по каждой категории и все настройки хранятся одной записью в cookie ядра и сохраняются между сессиями. Если выбранный предмет пропал из конфига группы или стал недоступен (другая команда, нет права), он просто не надевается.

## Отличия от оригинала

- Фича регистрируется как `Selectable` в `VipFeatureBase`: игрок настраивает её в `!vip`, а конфиг лежит в `vip.json` (в оригинале — отдельный модуль на `VipModule` с `GroupValue`, `SelectCategories` и `CategorySetting`).
- Формат конфига тот же (категории → список `name`/`model`/`team`/`required`), поля пишутся в нижнем регистре.
- Добавлены настройки видимости: показ своей экипировки и то, кто видит вашу и чью видите вы (в оригинале — только выбор предметов).
- Скрытие от игроков сделано через `Listeners.CheckTransmit` API CounterStrikeSharp, а не через `InvisPool` оригинального ядра.
- `required` проверяется через `AdminManager.PlayerHasPermissions` CounterStrikeSharp.
- Экипировка не создаётся для ботов.
