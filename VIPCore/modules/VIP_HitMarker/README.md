# VIP_HitMarker

Показывает частицу-хитмаркер перед прицелом VIP-игрока, когда он попадает во врага. Маркер видят сам стрелок и (по желанию) наблюдатели, которые смотрят за ним; остальным игрокам он не передаётся. Для хедшота можно задать отдельную частицу. Игрок целиком настраивает маркер в меню `!vip` (см. «Меню игрока»).

Порт модуля `HitMarker` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/HitMarker.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_HitMarker/VIP_HitMarker.csproj -c Release
   ```
2. Скопируйте папку `VIP_HitMarker` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Загрузите файлы частиц (`.vpcf` / `.vpcf_c`) на сервер и клиентам (Workshop-аддон или FastDL — зависит от вашей схемы раздачи ресурсов).
4. Добавьте фичу `HitMarker` в нужные группы `vip.json` (см. ниже) и перезапустите сервер или смените карту. `css_vip_reload` подхватит новые записи, но **частицы предзагружаются при старте карты**, поэтому новый `.vpcf` заработает только после смены карты.

Строки меню берутся из `lang/*.json` ядра (ключи `HitMarker` и `hitmarker.*`). Обновите `lang` ядра до версии с этим модулем, иначе пункты меню будут показаны ключами.

## Конфиг (`vip.json`)

Значение фичи — список маркеров:

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "HitMarker": [
          {
            "name": "Impact",
            "particle": "particles/impact_fx/impact_hit_effect.vpcf",
            "headshot": "particles/impact_fx/impact_hit_effect_kill.vpcf",
            "duration": 0.25,
            "distance": 60
          }
        ]
      }
    },
    "VIP2": {
      "Values": {
        "HitMarker": [
          {
            "name": "Impact",
            "particle": "particles/impact_fx/impact_hit_effect.vpcf",
            "headshot": "particles/impact_fx/impact_hit_effect_kill.vpcf",
            "duration": 0.25,
            "distance": 60,
            "offset_x": 0,
            "offset_y": 0
          },
          {
            "name": "Cross",
            "particle": "particles/hitmarker/cross.vpcf",
            "headshot": "particles/hitmarker/cross_hs.vpcf",
            "duration": 0.3,
            "distance": 80,
            "offset_x": 0,
            "offset_y": 5
          },
          {
            "name": "Screen",
            "particle": "particles/hitmarker/screen_flash.vpcf",
            "duration": 0.2,
            "distance": 0
          }
        ]
      }
    }
  }
}
```

Пути в примере — условные: `Impact` повторяет пример из оригинального плагина, а `Cross` и `Screen` — заглушки. Подставьте частицы, которые реально есть в вашем аддоне. Разные группы могут иметь разные наборы маркеров. `distance: 0` подходит для частиц, собранных как экранный эффект: они рисуются прямо на экране и расстояние игнорируют; чем больше расстояние для обычной частицы, тем крупнее она выглядит.

Имена полей — строго в нижнем регистре.

| Поле | Описание |
|------|----------|
| `name` | название в меню (обязательно, служит и идентификатором выбора — не меняйте его у уже выданных маркеров, иначе сохранённый выбор игроков сбросится на первый маркер группы) |
| `particle` | путь к файлу частицы `.vpcf` (обязательно) |
| `headshot` | необязательный файл частицы для попадания в голову; если пусто — используется `particle` |
| `duration` | сколько секунд живёт маркер, по умолчанию `0.25` |
| `distance` | расстояние от глаз вдоль направления взгляда, по умолчанию `60` |
| `offset_x` | сдвиг вбок относительно взгляда (положительный — вправо), по умолчанию `0` |
| `offset_y` | сдвиг по вертикали (положительный — вверх), по умолчанию `0` |

Запись без `name` или без `particle` игнорируется. Значения `duration`, `distance`, `offset_x` и `offset_y` из конфига служат значениями по умолчанию — игрок может переопределить их в меню. Все файлы из `particle` и `headshot` всех групп автоматически добавляются в предзагрузку карты (читаются прямо из `vip.json`).

## Меню игрока

Пункт `HitMarker` в `!vip` открывает меню:

| Пункт | Что делает |
|-------|------------|
| Маркер: имя | открывает список маркеров группы + «Выключить»; при выборе сразу показывает предпросмотр |
| Маркер на хедшот: Да/Нет | включает/выключает отдельную частицу для хедшота (показывается, если в группе есть `headshot`) |
| Длительность: N с | по клику переключает 0.1 → 0.15 → 0.25 → 0.4 → 0.6 → 1.0 с |
| Положение | подменю: расстояние (0–160; 0 — для экранных частиц), сдвиг по горизонтали и по вертикали (−40…40, шаг 10), «Сбросить положение» к значениям из конфига |
| Видят наблюдатели: Да/Нет | показывать ли маркер наблюдателям, которые смотрят за вами |
| Предпросмотр | показывает маркер с текущими настройками |

Без сохранённого выбора VIP получает первый маркер своей группы. Все настройки хранятся одной записью в cookie ядра и сохраняются между сессиями; пункты настройки скрыты, пока маркер выключен.

## Отличия от оригинала

- Фича регистрируется как `Selectable` в `VipFeatureBase`: игрок включает и выключает её переключателем в `!vip`, а конфиг лежит в `vip.json` (в оригинале — отдельный модуль на `VipModule` с `GroupValue`).
- Настройки маркера (выбор, хедшот, длительность, положение, наблюдатели) хранятся у каждого игрока отдельно, а не только выбор названия.
- Урон от огня (`inferno`) не создаёт маркер, чтобы он не пересоздавался каждые несколько кадров.
- Скрытие маркера от других игроков сделано через `Listeners.CheckTransmit` API CounterStrikeSharp.
