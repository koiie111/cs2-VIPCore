# VIP_Chat

Закрытый чат для VIP-игроков. Сообщение, начинающееся с префикса (по умолчанию `#`), видят только VIP — остальные игроки его не получают. Игрок целиком настраивает чат в меню `!vip` (см. «Меню игрока»).

Пример: `#го на B` → всем VIP в чате появится ` [VIP] Ник: го на B`, а обычные игроки ничего не увидят.

Порт модуля `VIPChat` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/VIPChat.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_Chat/VIP_Chat.csproj -c Release
   ```
2. Скопируйте папку `VIP_Chat` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Добавьте фичу `VipChat` в нужные группы `vip.json` (см. ниже) и выполните `css_vip_reload`.

Строки меню берутся из `lang/*.json` ядра (ключи `VipChat` и `vipchat.*`). Обновите `lang` ядра до версии с этим модулем, иначе пункты меню будут показаны ключами.

## Конфиг (`vip.json`)

Значение фичи — объект, все поля необязательны. Достаточно `"VipChat": {}` — тогда работают значения по умолчанию.

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "VipChat": {}
      }
    },
    "VIP2": {
      "Values": {
        "VipChat": {
          "tag": "[VIP+]",
          "prefixes": ["#", "$", "."],
          "colors": ["White", "Gold", "Green", "Purple", "Orange"]
        }
      }
    }
  }
}
```

Имена полей — строго в нижнем регистре.

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `tag` | `"[VIP]"` | метка перед ником. Пустая строка — без метки (пункты про метку в меню тогда скрыты) |
| `prefixes` | `["#"]` | с каких символов должно начинаться сообщение; игрок выбирает один из списка в меню. Служебные триггеры команд (`!`, `/` — из `core.json` CounterStrikeSharp) в качестве префикса использовать нельзя: такие сообщения всегда считаются командами |
| `colors` | вся палитра | цвета, из которых игрок выбирает цвет метки, ника и текста |

Доступные цвета: `White`, `Grey`, `Red`, `LightRed`, `Orange`, `Yellow`, `Gold`, `Lime`, `Green`, `LightBlue`, `Blue`, `Purple`, `Magenta`. Неизвестные названия в `colors` игнорируются; если не осталось ни одного — доступна вся палитра.

## Меню игрока

Пункт `VIP-чат` в `!vip` открывает меню. Каждый пункт переключается кликом, значение применяется сразу, меню открывается заново:

| Пункт | Что делает |
|-------|------------|
| VIP-чат: Вкл/Выкл | главный выключатель: при «Выкл» вы не отправляете и не получаете сообщения VIP-чата |
| Отправка: С префиксом / Все сообщения | в режиме «Все сообщения» каждое ваше сообщение уходит только VIP (команды вроде `!vip` по-прежнему работают) |
| Префикс: X | смена префикса по списку `prefixes` (виден в режиме «С префиксом» и только если в конфиге больше одного префикса) |
| Мои сообщения видят: Все VIP / Только союзники | ограничить получателей союзниками-VIP |
| Показывать метку: Да/Нет | показывать ли `tag` перед ником (если `tag` задан) |
| Цвет метки / ника / сообщения | выбор цвета из доступной палитры |
| Сбросить настройки | возвращает все параметры по умолчанию |

Цвета по умолчанию — как в оригинале: метка фиолетовая, ник золотой, текст зелёный. Все настройки хранятся одной записью в cookie ядра и сохраняются между сессиями.

## Как это работает

Модуль перехватывает пользовательское сообщение чата (SayText2), как и оригинал. Поэтому плагины мута/гага сохраняют контроль: сообщение замученного игрока до хука не доходит. Для сообщения VIP-чата подменяются текст и список получателей: убираются все, кто не VIP, у кого VIP-чат выключен или (при ограничении «Только союзники») кто в другой команде. Сам автор всегда видит своё сообщение. Из текста вырезаются управляющие символы (игрок не может подмешать цвета), длина ограничена 200 символами.

## Совместимость

- **VIP_Tag.** Если у игрока включён VIP_Tag, тот сам перерисовывает строку чата и отправляет её всем, поэтому сообщения с префиксом VIP-чата перестают быть закрытыми. Используйте `VipChat` и `Tag` в разных группах либо отключите `ChatTag` у групп, где нужен закрытый чат.
- Любой другой плагин, который сам печатает строки чата (чат-менеджеры), может обходить хук SayText2 — проверьте на своём сервере.

## Отличия от оригинала

- Фича регистрируется как `Selectable` в `VipFeatureBase`; конфиг лежит в `vip.json` (в оригинале — отдельный модуль на `VipModule`, всё жёстко задано в коде).
- В оригинале префикс `#`, метка `[VIP]` и цвета были зашиты; теперь метка, префиксы и палитра берутся из конфига группы, а игрок настраивает всё под себя в `!vip`.
- Добавлены режим «Все сообщения», ограничение получателей союзниками, выключатель получения и сохранение настроек в cookie.
- Игрок без VIP или без фичи в группе, как и в оригинале, пишет в обычный чат (сообщение с `#` уходит всем как есть).
- Из сообщения вырезаются управляющие символы и учитываются триггеры команд из `core.json` CounterStrikeSharp.
