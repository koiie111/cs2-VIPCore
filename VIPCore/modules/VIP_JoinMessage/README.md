# VIP_JoinMessage

Сообщения в чат о входе и выходе VIP-игрока. Набор готовых текстов задаётся в `vip.json` для каждой группы, а игрок целиком настраивает показ в меню `!vip` (см. «Меню игрока»).

Порт модуля `JoinMessage` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/JoinMessage.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_JoinMessage/VIP_JoinMessage.csproj -c Release
   ```
2. Скопируйте папку `VIP_JoinMessage` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Добавьте фичу `JoinMessage` в нужные группы `vip.json` (см. ниже) и перезапустите сервер или выполните `css_vip_reload`.

Строки меню берутся из `lang/*.json` ядра (ключи `JoinMessage` и `joinmessage.*`). Обновите `lang` ядра до версии с этим модулем, иначе пункты меню будут показаны ключами.

## Конфиг (`vip.json`)

Значение фичи — список текстов. Поле `leave` разделяет их на две категории: `false` — сообщение о входе, `true` — сообщение о выходе.

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "JoinMessage": [
          { "name": "Classic", "message": "{blue}VIP {red}{name}{default} зашёл на сервер", "leave": false },
          { "name": "Classic", "message": "{blue}VIP {red}{name}{default} покинул сервер", "leave": true }
        ]
      }
    },
    "VIP2": {
      "Values": {
        "JoinMessage": [
          { "name": "Classic", "message": "{blue}VIP {red}{name}{default} зашёл на сервер", "leave": false },
          { "name": "Boss", "message": "{gold}[{group}] {lime}{name}{default} вошёл — всем приготовиться!", "leave": false },
          { "name": "Classic", "message": "{blue}VIP {red}{name}{default} покинул сервер", "leave": true },
          { "name": "Bye", "message": "{gold}[{group}] {lime}{name}{default} ушёл, до встречи!", "leave": true }
        ]
      }
    }
  }
}
```

Имена полей — строго в нижнем регистре.

| Поле | Описание |
|------|----------|
| `name` | название в меню (обязательно, служит и идентификатором выбора — не меняйте его у уже выданных текстов, иначе сохранённый выбор игроков сбросится на первый текст категории). Для входа и выхода имена могут совпадать |
| `message` | текст сообщения (обязательно) |
| `leave` | `false` (по умолчанию) — сообщение о входе, `true` — сообщение о выходе |

В тексте работают:

- `{name}` — ник игрока, `{group}` — его VIP-группа;
- цвета чата: `{default}`, `{white}`, `{red}`, `{darkred}`, `{green}`, `{lime}`, `{blue}`, `{lightblue}`, `{purple}`, `{lightpurple}`, `{olive}`, `{yellow}`, `{lightyellow}`, `{gold}`, `{silver}`, `{grey}` и др. (любое имя из `ChatColors` CounterStrikeSharp, без учёта регистра). Неизвестные теги остаются как есть.

Запись без `name` или без `message` игнорируется. Если в группе нет ни одной записи категории, для неё используется стандартный текст из `lang` («VIP-игрок … зашёл на сервер» / «… покинул сервер»). Пустой список `[]` включает фичу только со стандартными текстами.

## Меню игрока

Пункт `JoinMessage` в `!vip` открывает меню:

| Пункт | Что делает |
|-------|------------|
| Сообщение о входе: Вкл/Выкл | объявлять ли ваш вход |
| Текст входа: имя | открывает список текстов входа вашей группы (скрыт, если в группе их нет) |
| Сообщение о выходе: Вкл/Выкл | объявлять ли ваш выход |
| Текст выхода: имя | то же для текстов выхода |
| Мои сообщения видят: Все/Союзники/Только я | кому показывается ваше сообщение |
| Чужие сообщения: Показывать/Только союзники/Скрыть | чьи сообщения о входе и выходе видите вы (доступно всем, в том числе не-VIP) |
| Предпросмотр сообщений | показывает только вам ваши тексты входа и выхода |
| Сбросить настройки | возвращает всё по умолчанию (оба сообщения включены, первый текст категории, видят все) |

Без сохранённого выбора VIP получает первый текст своей категории. Все настройки хранятся одной записью в cookie ядра и сохраняются между сессиями. Своё сообщение о входе вы всегда видите (кроме случая, когда сообщение отключено); о выходе оно вам, естественно, не показывается.

> Настройка «Чужие сообщения» действует для того, кто смотрит, поэтому у игрока без VIP отдельного меню нет — для него используется значение по умолчанию «Показывать».

## Как это работает

- Сообщение о входе отправляется через 2 секунды после подключения. VIP-данные загружаются асинхронно, поэтому если игрок ещё не определён как VIP, проверка повторяется каждые 2 секунды до 6 раз.
- Сообщение о выходе отправляется в момент отключения.
- Сообщения получают только живые игроки (боты пропускаются) в соответствии с настройками видимости владельца и зрителя; «Союзники» — игроки одной команды (за наблюдателей и неопределившихся «союзников» нет).

## Отличия от оригинала

- Фича регистрируется как `Selectable` в `VipFeatureBase`: игрок включает и выключает её в `!vip`, а конфиг лежит в `vip.json` (в оригинале — отдельный модуль на `VipModule` с `GroupValue`, скрытый из меню).
- Вместо одной пары строк `JoinMessage`/`LeaveMessage` в группе задаётся список текстов, из которого игрок выбирает; в оригинале у группы был единственный текст.
- Добавлены персональные настройки: включение входа и выхода по отдельности, кому показывать своё сообщение и чьи чужие видеть, предпросмотр, сброс.
- Цвета в тексте обрабатываются самим модулем (тегами `{red}` и т.п.), а не `ChatColorUtil` оригинального ядра; добавлен тег `{group}`.
