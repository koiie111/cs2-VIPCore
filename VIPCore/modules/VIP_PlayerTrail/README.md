# VIP_PlayerTrail

Рисует след за VIP-игроком: цветной луч (`env_beam`) или партикл-эффект. Игрок сам выбирает вариант (или выключает след) в меню `!vip`.

Порт модуля `PlayerTrail` из [ByDexterTR/CS2Plugins](https://github.com/ByDexterTR/CS2Plugins/blob/main/VIPCore/modules/PlayerTrail.cs) под API этого ядра (`VipFeatureBase`, `vipcore:core`).

## Установка

1. Соберите модуль вместе с остальными (CI кладёт его в `VIP_Modules.zip`) или вручную:
   ```bash
   dotnet publish VIPCore/modules/VIP_PlayerTrail/VIP_PlayerTrail.csproj -c Release
   ```
2. Скопируйте папку `VIP_PlayerTrail` в `addons/counterstrikesharp/plugins/` (рядом с `VIPCore`).
3. Добавьте фичу `PlayerTrail` в нужные группы `vip.json` (см. ниже) и смените карту либо перезапустите сервер — партиклы прекэшируются только при загрузке карты.

Строки меню берутся из `lang/*.json` ядра (ключи `PlayerTrail`, `playertrail.Disable`, `playertrail.On`, `playertrail.Off`).

## Конфиг (`vip.json`)

```json
{
  "Groups": {
    "VIP1": {
      "Values": {
        "PlayerTrail": {
          "Width": 1.5,
          "Lifetime": 2.0,
          "Colors": [
            "Красный #FF0000",
            "Голубой #00BFFF",
            "Радуга rainbow",
            "Случайный random"
          ],
          "Particles": [
            {
              "Name": "Огонь",
              "File": "particles/path/to/effect.vpcf",
              "Tint": "",
              "Radius": 0,
              "Lifetime": 0,
              "Offset": 10,
              "Follow": true
            }
          ]
        }
      }
    }
  }
}
```

Имена полей чувствительны к регистру (как в примере).

| Поле | Описание |
|------|----------|
| `Width` | толщина луча |
| `Lifetime` | сколько секунд живёт каждый отрезок следа (луча или партикла) |
| `Colors` | цвета луча. Формат строки: `<Название в меню> <значение>`; значение — последнее слово |
| `Particles` | партикл-эффекты (см. ниже) |

### Значения цвета

| Значение | Результат |
|----------|-----------|
| `#RRGGBB` | фиксированный цвет |
| `rainbow` | цвет плавно переливается по радуге |
| `random` | случайный цвет, новый на каждый раунд |

### Поля партикла

| Поле | Описание |
|------|----------|
| `Name` | название в меню (уникальное внутри группы) |
| `File` | путь к `.vpcf`. Сторонние эффекты должны быть у клиентов (Workshop-аддон / ResourcePrecacher) |
| `Tint` | перекраска эффекта (`#RRGGBB`, `R G B` или `rainbow`), пусто — без перекраски |
| `Radius` | радиус эффекта (control point 4), `0` — по умолчанию |
| `Lifetime` | время жизни отрезка; `0` — берётся общий `Lifetime` |
| `Offset` | смещение по высоте от ног игрока |
| `Follow` | `true` — один эффект, который всё время движется за игроком; `false` — эффект-«трассер» между точками пути, как луч |

## Поведение

- Пункт в `!vip` открывает подменю: «Выключить» + все цвета и партиклы группы. Выбор сохраняется в cookie ядра (`player_trail`) и переживает реконнект.
- Пока игрок ничего не выбрал, используется первый вариант группы (сначала цвета, потом партиклы). Если сохранённый вариант пропал из конфига группы — тоже первый.
- След рисуется только у живого игрока; отрезки короче 12 юнитов копятся, скачки длиннее 250 юнитов (телепорт, респавн) пропускаются.
- След удаляется при смерти, смене команды, выходе и потере VIP.

## Отличия от оригинала

- Нет per-viewer скрытия эффектов (`EffectHide`: «показывать всем / команде / только себе») — в этом ядре нет такого механизма, след видят все.
- Убраны поля партикла `Required` и `Team` (завязаны на систему прав ядра ByDexterTR).
- Нет интеграции с невидимостью (`InvisPool`).
